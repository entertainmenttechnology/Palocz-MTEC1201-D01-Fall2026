## Setting up a new p5 Assignment   

_Follow these instructions to set up a new p5 sketch on your computer:_

* Make sure you know which folder on your computer your GitHub repository is in (you can check this by opening GitHub desktop, right-clicking on the repository name in the top-left corner, and selecting "Reveal in Finder" for Mac or "Reveal in Explorer" for Windows)
* Create a new empty folder inside your main repository folder, and label it with the name of the assignment.  This will hold the files for your sketch.
* Open Visual Studio Code 
* Open the Command Palette (with command-shift-p on Mac, or ctrl-shift-p on Windows) and then start typing and select the command "Create p5.js Project".
* In the folder select window that opens, navigate to your GitHub repository folder, and select the new folder you made for the assignment, then click "Open" to create a sketch inside that folder.
* With the sketch folder open in the Visual Studio Code editor, select the sketch.js file from the file browser to the left. You will modify and add to the code in this file to create your sketch.
* To see your code run, click the "Go Live" button in the bottom-right status bar to open your sketch in a browser. When you save your file in Visual Studio Code, it should update the display in the browser.
* [Open the developer tools in your browser](https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Tools_and_setup/What_are_browser_developer_tools). Choose the console tab to see any output or errors from your code as it runs. 
  * You can open the developer tools quickly with the keyboard shortcuts [⌘ + ⌥ + I] for Mac or [Ctrl + Shift + I] for Windows.
* Open GitHub Desktop. It should show any new files and/or changes to existing files. 
* Commit these changes by typing a summary in the "Summary" box and clicking "Commit to main" on the bottom right.
* Click "Push Origin" to push your commits from your local computer to the cloud.
